# Semaforizaci-n-y-control-de-procesos-v-a-EWMA
Software analítico que automatiza el flujo ETL de reportes dimensionales de chasis mediante una interfaz Excel VBA y un motor en Python. Implementa semaforización EWMA con Sigma Adaptativa y Regularización de Ledoit-Wolf para muestras pequeñas (n≪p), identificando causas raíz con Grafos de Influencia y reportes interactivos 3D.
